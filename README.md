# Folder Aset Gambar — Dashboard UTS BI Kelas B (UNIMOR)

Simpan file gambar dengan **nama persis** seperti di bawah agar otomatis tampil
di dashboard. Tidak perlu mengubah kode.

| File | Isi | Tampil di |
|---|---|---|
| `foto_mahasiswa.png` (atau `.jpg` / `.jpeg`) | Foto mahasiswa asli | Kartu Identitas — lingkaran, `object-fit: cover` |
| `logo_unimor.png` (atau `.jpg` / `.jpeg`) | Logo resmi UNIMOR | Kartu Tentang Universitas Timor |
| `gedung_unimor.jpg` (atau `.jpeg` / `.png`, alternatif `kampus_unimor.*`) | Foto gedung/lingkungan kampus UNIMOR | Banner besar kartu universitas |

Catatan:
- Gunakan foto **asli** (jangan foto universitas lain).
- Jika file belum ada, dashboard menampilkan **placeholder** yang rapi + petunjuk ini.
- Identitas teks (nama, NIM, prodi, fakultas, semester, tahun akademik) diisi lewat
  panel **"Lengkapi / ubah identitas & foto"** di Dashboard — tanpa edit kode.
- Ukuran disarankan: foto ≤ 1 MB, kampus lebar ≥ 1200 px agar tajam dan cepat dimuat.
